# M2 Translation Engine API

This document provides a clean interface definition for M1, M3, and M4 to integrate with the Translation Engine.

## Initializing the Translator

You must initialize the `Translator` exactly once during application startup. The initialization process loads the 1.28 GB neural network into memory. 

```python
from translation.translator import Translator

# Initialize translator (provide phrase_bank_path for fast phrase matching)
translator = Translator(phrase_bank_path="data/verified_phrase_bank.json")
```

## `translate` Function Signature

```python
def translate(text: str, source: str, target: str, context: Optional[Dict[str, Any]] = None) -> Dict[str, Any]:
    pass
```

### Inputs

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `text` | `str` | Yes | The finalized utterance text to translate (e.g., from ASR). |
| `source` | `str` | Yes | The source language code (e.g., `"hin_Deva"`). |
| `target` | `str` | Yes | The target language code (e.g., `"sat_Olck"`). |
| `context` | `dict` | No | Optional dictionary mapping context for the translation, to be used in future iterations. |

### Expected JSON Output Structure

The API responds with a structured dictionary. Never rely solely on a text string, as failures must be handled cleanly.

```json
{
    "source_text": "बच्चों, इन फलों को गिनो।",
    "translated_text": "ᱜᱤᱫᱽᱨᱟᱹ ᱠᱚ, ᱱᱚᱶᱟ ᱡᱚ ᱠᱚ ᱞᱮᱠᱷᱟᱭ ᱯᱮ᱾",
    "source_language": "hin_Deva",
    "target_language": "sat_Olck",
    "translation_source": "indictrans2",
    "latency_ms": 645,
    "success": true,
    "error": null
}
```

### Possible Values for `translation_source`
- `"verified_phrase"`: The translation hit a verified phrase in our cache/bank.
- `"indictrans2"`: The translation was dynamically generated by the neural model.

## Error Handling

When the system encounters an error, `success` will be `false` and `error` will contain a descriptive string. You should not crash the Flutter App.

```json
{
    "source_text": "",
    "translated_text": null,
    "source_language": "eng_Latn",
    "target_language": "sat_Olck",
    "translation_source": null,
    "latency_ms": 2,
    "success": false,
    "error": "Unsupported language pair: eng_Latn -> sat_Olck"
}
```
